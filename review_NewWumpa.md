# Ревью репозитория NewWumpa

---

## 🔴 Критические проблемы

**README.md полностью сломан**

Весь контент завёрнут в ` ```markdown ` блок — на GitHub это рендерится как один большой блок кода, а не как отформатированный README. Структура файла выглядит так:

```
# NewWumpa          ← это видно
` ` `markdown       ← здесь начинается блок кода
# NewWumpa
...весь контент...
` ` `               ← здесь он закрывается
```

Нужно убрать обёртку ` ```markdown ` и оставить только содержимое внутри.

**Окно невозможно закрыть нормально** — `WindowStyle="None"` убирает системную рамку, но кнопки закрытия и сворачивания не подключены ни к каким обработчикам. Приложение можно закрыть только через Alt+F4.

---

## 🟠 Серьёзные проблемы

**Нет перемещения окна** — в отличие от LauncherLes1, здесь нет `DragMove()`. Окно без рамки, которое нельзя перетащить — это UX-проблема.

**Кнопки-заглушки без логики** — обе кастомные кнопки в `TopMenu` не имеют обработчиков событий. У первой кнопки `ColorAnimation` без свойства `To` — анимация не будет работать.

---

## 🟡 Проблемы кода и проекта

**`Title="MainWindow"`** — дефолтное название окна не изменено.

**Лишние `using` в `MainWindow.xaml.cs`** — `System.Text`, `System.Windows.Shapes`, `System.Windows.Navigation` и другие импортируются, но нигде не используются.

---

## 🟡 Структура и репозиторий

**Нет `.gitignore`** — в репозитории находятся `bin/`, `obj/` и десятки временных WPF-файлов вида `NewWumpa_12o1khkv_wpftmp.*`. Их около 30+ — это захламляет репо и делает историю коммитов нечитаемой.

Минимальный `.gitignore` для C#:

```
bin/
obj/
*.user
.vs/
```

**В артефактах сборки обнаружилось два разных имени пользователя** — `defaultuser100000` и `zxcvb`. Это может говорить о том, что проект открывался на чужой или школьной машине. Лишний повод добавить `.gitignore` — такие данные не должны попадать в репо.

**Опечатка в пути** — папка проекта называется `VSptoject` (должно быть `VSproject`). Не критично, но заметно.
